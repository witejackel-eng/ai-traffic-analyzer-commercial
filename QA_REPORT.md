## 7. Known Issues (non-blocking)

1. **Runtime provider switching requires restart.** The `Settings` UI persists the provider config to the DB, but `getProvider()` caches the provider instance in a module-level variable. Changing `AI_PROVIDER` in the DB does not hot-swap the active provider without a process restart. *Workaround*: restart the server after changing the provider. *Documented* in `docs/AI_PROVIDERS.md` and the config module's JSDoc.
2. **Video upload metadata is placeholder.** The upload route creates a `VideoAsset` with default metadata (180s, 1280×720, 30fps) rather than probing the real file with FFprobe. *Reason*: V1 ships the mock provider; real video probing is the documented local-inference extension point.
3. **PDF export is browser print-to-PDF.** No native PDF engine is bundled. The HTML report is print-ready (verified: `@media print` rules present). *Documented* in `CHANGELOG.md`.

## R1. Real Pipeline Architecture

```
REAL MP4 (data/samples/real-traffic.mp4, 640×360, 60s, 30fps, H.264)
  ↓ FFmpeg/ffprobe (real metadata extraction)
REAL duration/dimensions/fps/codec
  ↓ Python subprocess: mini-services/vision-worker/infer.py
REAL frame extraction (OpenCV VideoCapture)
  ↓ SSD MobileNet v1 COCO (ONNX Runtime, Apache-2.0)
REAL detections: class + confidence + bbox + timestamp + frame
  ↓ IoU Tracker (in-process)
REAL tracks: stable track_id across frames + trajectory + direction
  ↓ Geometry modules (segmentsIntersect, pointInPolygon)
REAL zone entry/exit + line crossings + dwell
  ↓ Rule engine
REAL events: count_crossing / zone_entry / zone_exit / stopped_vehicle / wrong_way / congestion / dwell_time
  ↓ Prisma → SQLite
REAL DB persistence: Detection + Track + Event rows
  ↓ Report generator
REAL exports: CSV / JSON / HTML
```
